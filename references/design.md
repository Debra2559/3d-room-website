# 视觉与交互规范（让生成的网站“像这一套”，而不是普通模板）

## 视觉语言：米白纸张 + 一个主色 + 一个荧光色 + 手写感

| Token | 默认 | 用途 |
|---|---|---|
| `--paper` | `#FFFDF9` | 面板底色（加 18px 点阵底纹） |
| `--ink` | `#1C2342` | 深海军蓝文字、深色卡片、选中态 |
| `--accent` | `#E2434F` | 樱桃红：主按钮、悬停气泡、英文副标题、手写小字 |
| `--lime` | `#D6F04F` | 荧光黄绿：大标题高亮笔、“和我聊聊”按钮、便签 |
| `--sky` | `#CBD7EA` | 白天背景（夜晚 `#151B36`） |
| 辅助色 | `#F9C6CC` 粉 · `#AFC3E6` 雾蓝 · `#F4EEE6` 珍珠 · `#E9DDF5` 淡紫 · `#EEF8C9` 淡绿 · `#FFE3CF` 蜜桃 | 拼贴卡片底色 |

字体（全部免费，模板先走 `fonts.googleapis.cn` 国内可访问，失败再走 `.com`，都失败就用系统字体）：
- 英文大标题 Gloock（衬线）；中文大标题 Noto Serif SC 900
- 正文 Instrument Sans / Noto Sans SC
- 手写英文 Caveat；手写中文 站酷快乐体 ZCOOL KuaiLe

固定的版式元素：
- 二级页面开头：`— 中文 · ENGLISH` 小眉标 → 中文衬线大标题 → 樱桃红英文衬线副标题 → 一段引言
- **拼贴卡片（bento）**：6 列网格，卡片圆角 22px、每张一个柔和底色、依次浮现；整行卡 / 半行卡交替；深色卡片用 ink 底 + 荧光色点缀
- 手写元素：贴纸略微旋转（±2–10°）、便签、虚线邮戳、手写体小字
- 首页左下：一行手写问候（主色）+ 衬线超大标题（关键词荧光笔高亮）+ 一句介绍 + 主按钮 / 次按钮
- 顶部：左 logo（衬线品牌名 + 手写 studio）、中间毛玻璃胶囊导航（中文 + 小号英文）、右边日夜切换

## 3D 房间
- 等距视角（相机方位角 ≈ 0.78 rad、俯角 ≈ 0.6 rad、FOV 30），圆形小岛 + 地板 + 后墙和左墙，墙顶有白色压条
- **卡通渲染**：MeshToonMaterial + 3 阶灰度渐变贴图；柔和阴影；不要写实材质
- 物件都用圆角盒 / 圆柱 / 球拼成，配色从调色板里取，可以用 canvas 在板子上画内容（便利贴、黑板、地图、海报）
- 氛围：漂浮的灰尘粒子、锅和咖啡机的蒸汽、串灯、夜晚台灯点亮、窗外白天蓝天白云 / 夜晚月亮和城市灯光
- Q 版小人：大头（头身比约 1:1.4）、大眼睛带高光、腮红、会眨眼、轻微呼吸晃动、转身看向被点的物件；点它会说话

## 交互细节（都是踩过的坑，生成或修改时必须保留）
1. **气泡标签**：屏幕空间的 HTML 按钮，每帧把物件顶部的 3D 点投影到屏幕。悬停时变主色、放大 1.12 倍、展开英文；点击区域比气泡大一圈（`::before` 外扩）。
2. **气泡位置用独立的 `translate` 属性**，`transform` 只做 `translate(-50%,-100%)`，`transform-origin: 0 0`。如果把位置也写进 `transform`，悬停的 `scale` 会把整个位置一起放大，气泡会跳走再缩回 → 来回闪烁。
3. **鼠标在气泡上时，镜头停止跟随鼠标**（视差系数归零），否则气泡会“躲”鼠标；平时鼠标视差幅度要小（≈ 0.4 倍）。
4. **气泡不能钻到顶部导航下面**：y 至少 96px（手机 70px），左右各留 70px；高度相差 < 40px 且水平距离 < 76px 的气泡互相推开。
5. **关闭后的二级面板必须 `pointer-events: none`**（包括所有子元素），否则透明面板会挡住下面的气泡和 3D 物件，表现为“点过一次就不好 hover”。
6. 点击物件 → 镜头先飞到物件前（约 0.65 秒）→ 再打开面板；按 Esc / 点 ESC 按钮 → 关面板、镜头回到全景；← → 键在经历翻页、产品切换时可用。
7. 面板打开时 3D 降帧（每 3 帧渲染 1 次），页面隐藏时停止渲染，省电。
8. 视频：`preload="none"`，点了封面上的“▶ 播放”才加载；关面板 / 切页面自动暂停；视频统一转成 H.264 MP4（HEVC 在部分浏览器不能播）。
9. 手机（≤ 760px）：导航移到底部、可横向滑动；面板几乎全屏；关闭按钮变成 34px 小圆 ✕；所有拼贴卡片变单列；气泡字号变小。
10. 3D 加载失败（没有 WebGL、three.js 下载不到）时自动退回 2D 卡片版，内容一样能看。three.js 加载顺序：本地 `vendor/three.min.js` → npmmirror（国内）→ jsDelivr → unpkg，每个 6 秒超时。
11. `prefers-reduced-motion` 时关掉动画。

## 修改已有网站时
- 永远在**最新版本**上改：先读当前文件 → 改 → 写回；改之前留一份备份（`_backup/index.before-xxx.html`）。
- 改动大的功能用“打补丁”的方式（字符串替换 / 脚本），不要整文件凭记忆重写，避免把别人刚改的东西覆盖掉。
- 每次改完至少检查：JS 语法、桌面 1440×900 和手机 390×844 两个尺寸的截图、无控制台报错。
