# 脱敏规则：个人网站是公开的，查看网页源代码也能看到全部内容

## 一、开工前先问（第 2 步之前问一次就好）

> 网站是公开的，任何人都能看到，包括“查看网页源代码”。这些信息你希望怎么处理？
> 1. 真名 → 只用昵称 / 英文名（推荐）
> 2. 公司 / 学校名 → 保留 ／ 脱敏成“某 AI 公司”“某大厂”“某 211 高校”
> 3. 具体数字（绩点、排名、业绩、营收、转化率）→ 保留 ／ 改成定性描述（推荐）
> 4. 所在城市 → 保留到城市级 ／ 只写“某一线城市” ／ 不写
> 5. 联系方式 → 只放一个对外邮箱（推荐单独注册一个、不含真名拼音）

## 二、默认永远不放（用户主动要求也要提醒风险）

- 手机号、身份证号、家庭住址、门牌号、精确定位、实时行程（“我现在在 xx”）
- 工牌、证件、门禁卡、带二维码 / 条码的图片，照片里能看清的车牌、门牌、快递单
- 薪资、合同条款、公司内部数据 / 未公开项目 / 内部系统截图、客户名单
- 别人的照片和姓名（同事、同学、朋友）—— 需要对方同意，默认打码或不放
- 未成年人的照片和信息

## 三、生成时自动做的事

1. **整站替换**：用户选了脱敏的名称，在 `SITE` 所有字段里统一替换（标题、正文、文章、AI 分身问答、`brand`、图片说明），不能只改显示的地方。
2. **数字定性化**（用户选了的话）：“采纳率 35%→46%” → “采纳率明显提升”；“GPA 3.8 / 排名 5/127” → 删除或“成绩优异”。
3. **不留隐藏内容**：删掉的东西要从 JSON 里真正删掉，不要只是不显示——源代码里能看到。
4. **AI 分身的资料同样脱敏**：`qa` 问答、后端知识库 `knowledge/*.md` 都会公开；只写愿意公开的内容；被问到隐私时回答“网站上没写，欢迎发邮件问我”。
5. **照片检查**：提醒用户检查照片里的校徽、工牌、公司 logo、屏幕内容、窗外能认出的地标（如果不想暴露住址）、照片 EXIF 定位（导出 webp/jpg 时去掉元数据）。
6. **品牌名 / 域名**：如果用户想完全匿名，提醒品牌名和域名不要用真名拼音或缩写。
7. **场景里的细节**：霓虹灯牌、A 字黑板会显示 `brand` / `name`；时钟、窗外风景不要暗示具体城市（除非用户愿意）。

## 四、交付前扫描（能跑代码就真的跑一遍）

把最终的 `SITE` JSON 当文本扫描，至少检查：
- 用户说要隐藏的真名、公司名、学校名、城市名是否还出现（包括拼音、英文名、缩写）
- 手机号 `1\d{10}`、身份证 `\d{17}[\dXx]`、邮箱（是否只剩对外邮箱）
- 百分比、排名、金额等数字（用户选了定性化时）
- 图片 / 视频文件名里是否带真名

扫描结果写进交付说明的“脱敏清单”，明确告诉用户：哪些已处理、哪些保留了、哪些需要他自己再看（比如照片内容）。
