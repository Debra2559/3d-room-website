# 知识库：AI 分身只会根据这个文件夹里的内容回答

（只有接了真 AI 时才用得到，见 references/deploy.md。演示模式用的是 index.html 里 chat 模块的 qa 问答。）

- 新建 .md 文件放进来就行，第一行写 `# 标题`，正文用空行分段，可以用 `## 小标题`。
- 文件名以 0 开头的（`00-profile.md`、`01-experience.md`）每次对话都会完整交给 AI：放最核心、最常被问的信息，尽量短。
- 其他文件会被切成小段，只有和访客问题相关的几段会交给 AI：放文章、项目细节、常见问答。
- 改完要重新部署，AI 才读得到。
- ⚠️ 这个文件夹会随网站公开，不要放手机号、住址、薪资、公司内部信息等不想公开的内容。
